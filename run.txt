[Option 1: Quick 1-Click Run via Script]
--------------------------------------------------------------------------------
Simply open Command Prompt (cmd) in this project folder and run:
    run_backend.bat


[Option 2: Step-by-Step Manual Run in Windows CMD]
--------------------------------------------------------------------------------

Step 1: Open Command Prompt (cmd.exe) and Navigate to Project Directory:
    cd /d c:\Users\krvam\OneDrive\Desktop\ai_meeting\AI_Meeting_Backend

Step 2: Activate the Virtual Environment:
    venv\Scripts\activate

Step 3: Ensure Required Storage Folders Exist:
    if not exist uploads mkdir uploads
    if not exist uploads\clips mkdir uploads\clips
    if not exist data\chroma mkdir data\chroma
    if not exist nemo_cache mkdir nemo_cache
    if not exist data mkdir data

Step 4: Verify the Offline Embedding Model:
    python -m backend.scripts.ensure_embedding_model

Step 5: Start the Uvicorn ASGI Server:
    python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
